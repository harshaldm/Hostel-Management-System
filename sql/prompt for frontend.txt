Build a full-stack **Hostel Management Dashboard** using **Node.js** where the backend and frontend exist in one application.

The system already has a MySQL database with two major modules:

1. Room Management
2. Mess Management

The application should first open with a **Login Selection Screen**:

* Admin Login
* Student Login (placeholder for future expansion)

For now, only implement **Admin Login**. No strong security needed yet. Use a simple login flow that can later be upgraded with JWT / sessions / role-based auth.
